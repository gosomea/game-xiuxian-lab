# 天轮剑阵分支交付

对应 [[node:wheel]]，目标为 [[goal:wheel]] 与 [[goal:quality]]。实施依据为 `notes/implemented/gameplay/2026-10-10-sword-spell-exploration.md`，基线 `b4117cb`。

按住左键，剑沿带后向深度的螺旋缓入身后完整双轮；入阵时剑尖由切向连续转为径向。松开锁定阵心与落点，等待当前剑完成入阵，再将剑尖平滑转向各自曲线的首切线；每组六把交错齐射。飞行进度使用加速曲线，剑尖由三次 Bézier 导数驱动，最后剑尖接地、青色小环扩散、剑影与尾迹衰减。金色法环有四道细环、反向旋转刻度、符纹与较淡内侧交线，飞剑以青色批量网格绘制。角色的双臂结阵与释放姿势通过共享请求驱动。

默认参数：内轮12剑、半径1.15m；外轮24剑、半径1.9m；阵心高3.05m、身后1.15m；逐剑出现0.025s、螺旋入阵0.42s、转剑0.22s；每组6剑、组间0.11s；最短飞行0.72s、参考速度28m/s、进度幂1.55；接地消散0.38s、结束冷却0.38s。满轮生成后约1.30s全部入阵；快速点按至少六剑均匀绕完整内圆，约0.55s入阵后也有完整转剑与发射。

状态和参数全部属于 `HeavenlySwordWheelComponent`，能力仅缓存退场清理所需的组件引用。逻辑时钟来自 `manager_time()`；View 使用 `logic_time`，不模拟或写入组件。无跨能力引用，无阻塞或时停账目。蓄势换招取消；松开后换招继续完成且不抢其它招姿势；共享取消序号变化、卸载和退场清空本包数据。每剑每目标一份命中账本，命中仅登记木桩记录与轻反馈。

接口：装配 `HeavenlySwordWheelComponent` 和 `HeavenlySwordWheel`；创建 `HeavenlySwordWheelView`，挂到宿主后 `bind(data)`。读取共享 `FORM_WHEEL`、`aim_point`、`aim_surface_point/valid/normal`、`cancel_generation`；写 `record_cast`、当前选中招式的姿势请求与 `record_feedback`。View 只读 `phase/logic_time/center/direction/ring_angle/ring_alpha/swords/impacts`。逐剑字段包含 `ring/angle/state/position/forward/scale/alpha/trail`，以及轨迹控制点、发射时间、目标与命中账本，便于连续画面与运动样本验收。

末端接触采用共享几何常量 `TIP_LENGTH=0.702`，按实际显示尺度回推剑格。散布落点逐剑查询 `collision_mask=2` 地形，避开 layer1 木桩；无碰撞夹具时沿用明确给出的地面点与法线。高台末段保证朝地面法线反方向落下；近距离缩短曲线控制臂，避免越过落点后反飞。参考速度、冷却和节奏是探索起点，本分支不引入伤害、经济或平衡结论。
