# HairSample Male 来源摘录

- 资产集合：VRoid Studio CC0 models
- 页面：https://opengameart.org/content/vroid-studio-cc0-models
- 页面作者字段：VRoid Project（由 hecko 提交）
- 页面许可字段：CC0
- 页面发布日期：2024-12-24
- 本地归档日期：2026-09-19
- 页面文件：`hairsample_male.zip`，页面标注 15.5 Mb
- 格式：VRM 0.x，基于 glTF 2.0

页面说明这些模型来自 VRoid Studio alpha 版本，由 VRoid 明确以 CC0 发布；Base 与 HairSample 由 VRoid Studio 0.14.0 导出且未启用优化。页面同时说明可以把 `.vrm` 扩展名改为 `.glb` 用作普通 glTF，但会失去 toon 材质信息。本路线保留原始 `.vrm`，构建时只对副本进行 Blender 导入与改造。

许可原始说明页：https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use
