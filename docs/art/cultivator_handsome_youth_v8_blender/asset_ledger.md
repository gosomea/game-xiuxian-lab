## 已知限制（如实记录）

1. **outfit 非全对称**（3646/8030）：短摆/外层下摆与领口用按角度曲线，左右片在数值上不镜像；
   另有腰封扣等有意居中的部件。body / head / hair 全对称。
2. **非流形边 436 条**：集中在衣物与头发的 Solidify 壳边与扫掠端盖，非水密。
3. 未做 UV 展开；材质为纯色分区，无贴图。
4. 面部是贴合曲面的浅浮雕薄片，极侧视角会看到片层厚度。
5. 鞋靴为深色短靴（非赤足），脚尖朝向靠鞋楦前伸与特写图证明。
6. 三片披发之间是**几何缝隙**而非真实发丝，近看仍能读出是三块厚片。
