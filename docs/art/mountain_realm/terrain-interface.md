## 山体碰撞（实测事实）

- 五峰碰撞节点名不变：`MainPeakCol` / `NorthPeakCol` / `WestPeakCol` / `EastRidgeCol` / `FrontMesaCol`。
- **合起来覆盖整片可走谷地与山面**：高度场网格按“最近峰”归属分面，因此不只山壳有碰撞，
  谷地起伏同样有；5 节点共 22,608 四边形 / 45,216 三角形。
- **三角绕序朝上**（Godot +Y，导出 GLB 实测 45,216 up / 0 down）：`to_blender=(x,−z,y)` 会翻转手性，
  若按自然顺序 `(i,j)→(i+1,j)→(i+1,j+1)` 会得到朝下法线，单面 trimesh 从上方降落会穿地。
  生成器已加 `CHECK collision_normals_up` 硬校验，`non_up` 必须为 0。
- **碰撞与可见地形同源**：同一 `terrain_height()` 采样，可接近区域偏差为 0；
  关键平台/屋体碰撞盒维持 75 盒原值不变。
- 地形代理只重建山体与谷地碰撞；建筑碰撞归庭院代理。

## 审计项落实（2026-09-18）

| 审计 | 落实 |
|---|---|
| ①峰脊不得侵占楼梯/门洞/月台 | 建筑/楼梯/落点/通道矩形内地形严格等于台顶：`channel_intrusion_m=0.0`（1,938 个平台采样点）；峰脊另有外扩 12 m 的专用禁止区 |
| ②谷地可见面不得低于 y=0 | 谷地基面 `max(0, …)`，实测 `valley_floor_min_y=0.0`（可玩 bounds 内非平台点），脚不再悬空 |
| ③碰撞覆盖完整谷地 | 按最近峰分面，5 节点覆盖全图；**不再是只有山峰有壳** |
| ④窄尖鳍/矩形平台边 | 峰脊改宽体（半径 22–28、短长轴比 0.92–0.95）+ 圆钝包络；平台边成簇挡土石过渡 |
| 三角法线 | 可见与碰撞网格绕序统一朝上，导出后实测 0 个朝下面 |
