# 水墨湖岸样板

日期：2026-10-05。状态：exploring。

## 问题

暖纸、白墙墨瓦、淡粉花树、灰青湖面和远山，与现役修士在步行和御剑中是否协调？

## 入口和操作

从「角色移动」目录进入「水墨湖岸样板」，也可直接运行：

```sh
./run.command res://levels/experiments/character_movement/ink_lakeside_sample.tscn
```

WASD / 方向键移动，Shift 疾跑，Space 跳跃或御剑上升，Ctrl 下降，F 起飞 / 收剑，滚轮缩放，R 重置，Esc 返回，H 详情。所有角色行为复用现役三项能力与完整输入入口。

## 观察路线

- 出生点沿岸向塔前行，检查小比例人物、白墙、黑瓦和树色是否协调。
- 走上石桥到小岛，观察水域留白与路面可读性。
- F 起飞，Space 上升，松开悬停；比较绕塔、俯看湖岸、收剑降落。
- 滚轮拉近观察现役动作和本场景人物材质，拉远比较远山层次。

## 当前范围

仅为移动与美术的组合样板。塔和民居不提供室内，远山是装饰，不包含战斗、任务或世界地图实现。
