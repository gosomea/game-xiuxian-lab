# 实验：六种剑术与共享剑指施法

使用者确认“剑法我觉得 ok”，本轮探索完成，`sword_combat` 为 `ready`，可供独立组合实验复用。入口为 `res://levels/experiments/sword_combat/sword_workbench.tscn`。本轮决定见[六招决策](../../notes/implemented/gameplay/2026-10-10-sword-spell-exploration.md)。

|---|---|
| 剑气 | 月牙剑光、方向出手与穿透命中 |
| 飞剑出击 | 本命剑沿弧线出击、命中与回收 |

六招各为独立 Capability 叶子包，输入与表现契约共用 `shared/sword_cast`；后三招各有独立数据 Component 与 View。能力模拟轨迹并登记三维命中，表现只读数据。共享修士提供移动、疾跑、跳跃与御剑，共享 CameraRig 保持唯一相机写入。飞剑离身期间仍阻止御剑，御剑期间仍阻止本命剑出击。

六招共享胸前剑指结诀、食中二指并拢、约 105° 前下方发令、全程掌心朝角色左侧与平滑收势。原身体与七段动作库保留，剑法装配通过独立十六骨右手补充手型。[剑指决策](../../notes/implemented/art/2026-10-10-sword-finger-gesture.md)与[资产台账](../art/sword_finger_gesture_20261010/asset_ledger.md)记录当前方案和保留版本。

## 验证与操作

六招实现与组合验收见[执行证据](../10-plans/sword-spell-exploration/validation/20261010-final/report.md)。最终剑指版本已有 2862 项回归与 32 项图形检查通过，连续采样覆盖六招的起势、发令和收势，实际导入手部掌心向左误差小于 1°；详见[动作验收](../playtest/2026-10-10-sword-finger-gesture/report.md)。这些结果是对应版本的证据，不将使用者认可扩大为未运行的检查。

鼠标指向，左键释放剑气/飞剑；按住并松开释放四种蓄势剑术。C 或按钮换招；WASD / 方向键移动、Shift 疾跑、Space 跳跃或上升、Ctrl 下降、F 起飞或收剑、R 重置、Esc 返回。

## 保留边界

当前目标是五根静止木桩，没有敌人 AI、生命、伤害、胜负或完整成长规则。招式参数是探索起点，`ready` 不表示最终平衡与成品美术完成。

使用者曾反馈移动时点击不能施法；视口事件诊断中六招在步行与疾跑时均启动，尚未复现设备或嵌入窗口的点击丢失原因，本轮没有修改输入逻辑。若再次出现，需在发生问题的窗口记录真实按下/松开事件，不能将自动事件诊断视为桌面输入问题已解决。
