# 杭州西湖 · 夕照入云

入口：顶层实验目录 → 角色移动 → 最后一项「西湖夕照 · 穿云」。独立场景：`res://levels/experiments/character_movement/west_lake_sunset.tscn`。

```sh
./run.command res://levels/experiments/character_movement/west_lake_sunset.tscn
```

## 游览

从东岸湖滨出发，可以沿环湖岸线、白堤断桥与苏堤六桥步行。F 御剑可到三座湖心岛及雷峰塔前收剑降落。按住 Space 直升，约 5 秒进入云底、约 7 秒越过云顶，继续升空俯瞰云海与西湖；Ctrl 下降。人物保留现役模型、七段动作和共享移动参数。

| 操作 | 按键 |
|---|---|
| 移动 / 疾跑 | WASD 或方向键 / Shift |
| 跳跃 / 御剑上升 | Space |
| 起飞 / 收剑 | F |
| 御剑下降 | Ctrl |
| 环绕视角 | 按住右键拖动，Q/E 转向 |
| 缩放 | 滚轮，Z/X |
| 镜头模式 | 1 环绕、2 跟随、3 四向、4 俯览 |
| 投影 / 全景 | V 正交与透视切换，M 西湖全景 |
| 返回出生点 / 返回目录 | R / Esc |
| 展开操作说明 | H 或 F1 |

默认透视视角适合近身游览与穿云；V 切换到强调纸上画卷的正交视角。全景覆盖压缩湖景，地面全景暂隐云片以看清堤岛。落水回湖滨。镜头跟随飞行高度，失焦后清输入并保持已开启的御剑悬停。

这是一张风格化压缩的可游览综合场景，杭州街区与地标为简化轮廓；没有城市全域、建筑室内或任务。移动模块仍处于 exploring。资产与验收见 [台账](../art/west_lake_sunset/asset_ledger.md)、[运行报告](../playtest/2026-10-06-west-lake/report.md)。
