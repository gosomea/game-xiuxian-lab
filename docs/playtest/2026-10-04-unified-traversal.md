# 全场景移动与御剑验收 · 2026-10-04

## 结果与范围

八个使用现役修士的移动场景通过同一角色入口提交完整输入，地面移动、疾跑、跳跃、御剑全部可操作。
共享三能力仍由 `ActorAssembly` 装配，物理提交保持在角色根。
镜头实验室、移动庭院新增跳跃和御剑输入，地形接触训练场新增御剑输入。
庭院与地形场保留镜头水平约束，取消高度夹取，使镜头能跟随御剑上升。
决策依据：[统一输入](../../notes/implemented/gameplay/2026-10-04-unified-traversal-scene-input.md)。

## 统一操作

| 按键 | 地面 | 御剑 |
|---|---|---|
| WASD / 方向键 | 步行 | 水平飞行 |
| Shift + 方向 | 疾跑 | 使用共享御剑速度 |
| Space | 单次跳跃，按住不连跳 | 上升 |
| Ctrl | 下降输入不改变地面移动 | 下降 |
| F | 起飞 | 收剑并恢复重力 |
| R | 回出生点并清理输入 | 关闭御剑、解除阻塞并回出生点 |

御剑松开方向及升降键悬停；失焦清理输入并保留御剑悬停。
动作工作台预览模式隔离真实角色操作，Space 仍控制预览播放。
