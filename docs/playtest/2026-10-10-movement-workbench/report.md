# 移动综合工作台验收（2026-10-10）

综合工作台已完成当前范围，登记为移动目录首项；移动模块与十一项子实验均为 `ready`。参数实时预览、单项行为装卸、全实验室三维默认与跨进程继承均通过技术验收。

## 打开与使用

从顶层目录进入「角色移动」→「移动综合工作台」，或在仓库根运行：

```sh
./run.command res://levels/experiments/character_movement/movement_workbench.tscn
```

侧栏分「移动」「镜头」「其他组件」。可调整步行、疾跑、起跳、空中水平移动、御剑、四种视角、投影与其他注册组件的导出参数；三维坐标分行显示 X/Y/Z。行为开关卸下或恢复平面移动、跳跃、御剑和镜头。默认视角放在镜头页最上方。

修改立即应用；点击「保存为全局默认」后，所有共享三维修士与 CameraRig 的实验（包括剑法工作台）和下次启动沿用。保存于本机 `user://lab_defaults.json`，只覆盖改过的字段。「撤销未保存」回到已保存设置；「恢复原始默认」清除覆盖并保存。二维坊市保持独立像素尺度。

WASD / 方向键移动，Shift 疾跑，Space 跳跃 / 御剑上升，Ctrl 下降，F 起飞 / 收剑；1–4 换镜头、右键环绕、R 复位角色、Esc 返回。GUI 获得焦点时正常编辑字段；点击世界区域可继续操作角色。

## 验收

环境为 Godot 4.6 stable / macOS Apple M4 Pro。采用 CLI 与原生游戏窗口；键鼠事件通过 `Input.parse_input_event` 派发，截图来自真实游戏视口。本次未使用 Godot MCP，也未在编辑器嵌入 Game 视图进行人工操作。

| 验收点 | 结果与证据 |
|---|---|
| 导出字段发现与合法值 | PASS；运动、剑法、木桩与 CameraRigConfig 参数可编辑，拒绝瞬态输入、非法数值、未知模式与上下限倒置 |
| 疾跑与空中水平速度 | PASS；窗口键盘把疾跑改为 6.5，Shift+D 的真实水平速度为 6.5 m/s；调度器验证空中独立速度 3.5 m/s、关闭疾跑回到步行 2.0 m/s |
| 单项装卸与所有权 | PASS；御剑中卸跳跃保留同一个御剑实例、状态和阻塞；外部能力冲突不会被认领或删除，失败禁止保存 |
| 御剑与重力 | PASS；卸下御剑清理飞行状态、视觉及自身阻塞，基础重力恢复；全部行为卸下仍保留重力与碰撞 |
| 镜头卸载与恢复 | PASS；四个模式节点实际移出调度器，捕获释放且相机停止写入；恢复原模式并保留原有相机写入归属 |
| 全局组件参数 | PASS；庭院、西湖与剑法读取疾跑和镜头覆盖；剑法装配读取剑气速度，木桩读取命中半径 |
| 场景与进程继承 | PASS；窗口保存后切换庭院沿用设置；自动测试启动第二个 Godot 进程，验证速度、跳跃卸载和全景镜头 |
| 保存与恢复 | PASS；未保存状态、撤销、恢复原始默认、损坏 JSON 回退及写入失败如实反馈；测试使用隔离文件，未改真实用户设置 |
| 导航与小窗口 | PASS；114 条目录验收通过，十一项入口与返回链可运行；1280×800 与 960×600 画布下按钮可达、参数可滚动，镜头页不撑宽侧栏 |

数值基线未改变：步行 2.0、疾跑 4.2、起跳 6.0、重力 18.0、御剑 22.0、升降 12.0。空中水平速度默认 0，沿用地面速度。无碰撞恒重力公式给出默认跳跃理想顶点 1.0 m、腾空时间约 0.667 s；这些是解析参考，数值选择与手感仍由使用者调整。详见[参数探针](parameter_probe.json)。

2172 条运行时断言（包含 95 条设置专项断言）、31 条门禁负向控制与窗口 30 条断言均通过；具体套件结果与执行命令见[结构化验收记录](acceptance.json)。静态 Tier 0 门禁全部通过。

## 边界

本工作台编辑注册组件的导出参数；共享输入、瞬态状态与内部渲染数组不进入全局设置。卸载的是行为 Capability，共享数据继续供其余能力和唯一物理提交点使用。新登记组件可自动发现参数，其装配消费者需显式应用默认值。

技术验收覆盖机制与布局，未替使用者评价连续手感、美术或最终平衡。本机默认的跨机器导出暂未提供。决策与接口归属见[综合工作台 note](../../../notes/implemented/gameplay/2026-10-10-movement-global-workbench.md)。
