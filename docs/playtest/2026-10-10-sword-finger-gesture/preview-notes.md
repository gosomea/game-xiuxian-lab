# 预览迭代记录

首次窗口运行保存于 `initial/`。手腕连续性初始采样发生在 SkeletonModifier3D 修改前的骨架阶段，不能代表画面动作；手部特写也因此瞄到人物腰部。这次运行的局部 PASS 输出不作为最终验收证据，运行在巨剑末帧后没有继续产出渲染信号，主动终止。最终脚本通过 `modification_processed` 读取真正修改后的姿态，并将验收窗口置顶，重新进行六招验收。

初始手掌面环方向不一致，修正版重新计算闭合网格朝外法线，并收紧拇指；前版手部源、导出和两张预览保留在 `docs/art/sword_finger_gesture_20261010/initial/`。首次运行证据误写入 `src/docs/`，完整移入本报告的 `initial/`，不丢弃资产。

首次完整运行测试的新增姿势套件选中了手部 AnimationPlayer 而不是身体 AnimationPlayer，导致重复报 idle 不存在；修正为显式选择带 idle 的身体播放器。该次计数不视为有效全绿；其原始日志保留在 `diagnostics/initial-runtime.log`，随后完整回归无错误通过。

第二、三次窗口保存在 attempt2/ 和 attempt3/：第二次仍受到原生鼠标与自动镜头更新影响，人物转身混入腕部采样；第三次固定瞄准并预先面向目标后，暴露截图长帧导致姿势混合直接收回的跳变。共享表现层限制长帧的混合、腕部目标位移与转角，缓存随身体平移和转向；新增两百毫秒长帧和身体移动回归断言。窗口瞄准通过每个物理帧的场景输入入口固定到同一点，按下与松开走工作台原输入处理接口，避免桌面鼠标干扰近景。

第四次窗口 26/26 通过，但近景审阅拒绝旧手残片与平面化肤色，全部证据保留在 attempt4/。进一步修正腕口几何筛选、闭指关节、双指间距，并增加指甲和法线填光；skin-preview/ 的天轮近景用于外观审阅，6/6 检查通过，不代替最终六招验收。Dummy renderer 不支持 Mesh Shader 实例参数回读，首次添加填光 Shader 的无图形检查出现 material null；无图形档改为保留导出材质，随后同套件 23/23 无错误通过。

第五次窗口 26/26 通过，证据保留在 attempt5/。第六次将采样延伸到每招 320 次循环时发现 PNG 截图本身会经过额外渲染帧，循环迭代并不等于逐渲染帧；天轮收势的 2 项指标因此把多帧累计变化误作一帧变化，完整证据保留在 attempt6/。最终观察器在每次骨骼修饰完成时记录姿态，并用真实 process_frame 序号去重，覆盖结诀、发令与完整收势，保留逐帧位置、旋转和 delta。

第七次的前四招逐渲染帧指标通过，但窗口在巨剑阶段提前结束，exit 0 伴随未完成协程的资源泄漏警告，没有完整验收结论；证据保留在 attempt7/。尝试隐藏主窗口时 Godot 拒绝修改主窗口可见性，offscreen-preview/ 保留该错误与实际天轮渲染。最终改用最小化的原生窗口与 UPDATE_ALWAYS SubViewport，截图时显式 force_draw，不遮挡桌面，继续用真实 OpenGL/Metal 渲染完整六招。

使用者指出手部莫名转向，并明确结诀正上、发令约 90–120° 朝斜下方。旧根目录的第八次图形验收虽通过连续性指标，但不满足这次方向要求，保留作比较。修正腕部旋转基准，采用固定侧轴 105° 俯转、独立完整旋转缓存；方向断言测量真实修改后的手骨，覆盖五种姿势与瞄准变向。`upright105-preview/` 为单天轮预览，`upright105/` 为最终六招证据。

105° 方向的首次完整窗口保存在 `upright105-attempt1/`：剑气、飞剑与普通剑阵在姿势权重归零时立即退出腕部修饰，分别出现 0.747、0.810、0.798 rad 的最后一帧突转，26 项中 3 项失败。修正为腕部旋转持续返回基础动画、误差小于 0.02 rad 才交还，新增退出连续性和归位断言。第二次完整窗口 `upright105/` 为最终结果：26/26，0 失败，六招各 320 连续帧；最终完整回归 2855/0，新姿势套件 47/0。

使用者指出发令后掌心朝天，要求一直朝角色左侧。前版把掌宽轴当成固定轴，导致手指俯转时掌心抬向上方；改为固定原生腕骨负 Z 的掌心法线，掌宽轴随手指转动。剑法装配的垂手基准也朝身体内侧，使收势时保持侧掌，不再回到独立手部朝外的旧基准。`palm-left/` 保存最终六招真实图形证据：32/32，0 失败；完整回归 2862/0，手部姿势套件 54/0。采样改用最终 skeleton_updated 与真实导入手部 Wrist，1920 个连续帧全部满足掌心朝左误差小于 1°。旧版资产与证据完整保留。
