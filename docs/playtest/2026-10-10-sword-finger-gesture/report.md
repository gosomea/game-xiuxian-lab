# 六种剑术的剑指施法优化

使用者以右手胸前剑指诀为参考，授权优化人物施法。结诀指向正上方，发令按使用者最新要求俯转约 **105°**，指向前方偏下 15°；**掌心全程朝角色左侧**，手指改变方向时掌宽轴随动，发令和收势均不翻掌朝天。六种剑术共用新的手型和动作表现；Component、Capability、命中时序、冷却、移动与七段基础动作保持现有契约。依据：[共享施法决策](../../../notes/implemented/art/2026-10-10-sword-finger-gesture.md)。

## 已交付内容

- 独立右手资产：腕骨与五指各三根骨，真实蒙皮和可编辑结诀动画；食指与中指伸直并拢，无名指、小指和拇指收拢。
- 屈肘起势：剑诀立在胸前，右肘在身侧向下。剑气、飞剑与普通剑阵向前下方发令；天轮以剑指催动；巨剑与剑雨先举诀再下压手臂，指向沿同一侧轴俯转。
- 平滑收势：腕部目标每帧位移不超过 4.5 厘米，腕部旋转插值不超过 0.32 弧度，混合权重单步不超过 0.15。长帧继续逐步过渡，身体平移和转向时手部目标随身体走。施法权重归零后手腕继续归位，接近垂手基准才停止缓存，掌心继续保持向左，避免收势末帧突转。垂手保留基础动画的手指方向投影，独立右手掌心朝身体内侧。
- 装卸隔离：右手挂在原身体手腕；原右手局部三角形通过独立 ArrayMesh 索引隐藏。卸载即时移除借用节点并还原原共享 Mesh，可在同帧再次装配。

原人物模型没有手指骨的事实仍然成立；剑法装配提供独立十六骨手部。旧身体、原动作库和探索资产全部保留，新源与 GLB 使用本地 Git LFS。[资产台账](../../art/sword_finger_gesture_20261010/asset_ledger.md)记录源、导出、结构回读与初版比较资产。

## 使用

从实验室进入「剑法战斗」。点击招式按钮或 C 切换；左键释放剑气、飞剑，按住并松开左键释放剑阵和新三招。原 WASD、Shift、Space、F、Ctrl、R 入口继续使用。

近景预览便于看清手型；正式 2.5D 镜头中的手指可读性受画面尺度限制。动作、美观与参考图贴合度需使用者最终判断。

## 复现图形验收

在仓库根执行 `Godot --path src --script res://tests/sword_finger_gesture_playtest.gd -- --offscreen`。`--offscreen` 使用最小化原生窗口的 GPU 渲染，不是无图形 Dummy renderer；`--form=heavenly_sword_wheel` 可单独观察天轮，`--evidence-dir=<绝对目录>` 用于另存证据。源文件中的默认目录是本报告下的 `palm-left/`，旧版本窗口证据保留在根目录与各次尝试目录。
