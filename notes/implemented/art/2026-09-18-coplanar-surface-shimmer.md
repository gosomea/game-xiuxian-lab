# Note: 装饰面共面与透明穿叠导致的跨场景地面闪烁

Status: implemented

## 问题

使用者在实际运行中报告三处实验的**地面在移动时持续闪烁**（报告原话包含「剑法实验」「压力」「易懂」，入口映射见下表）：

| 报告序号 | 场景 | 判定依据 |
|---|---|---|
| 1 | 御剑飞行训练场 `src/levels/experiments/character_movement/sword_flight_course.tscn` | 用户原词为「剑法实验」，仓库当时没有已实现的剑法战斗场景，映射到唯一存在的御剑飞行场景 |
| 2 | 状态切换压力场 `state_transition_lab.tscn` | 明确点名：切换/失焦实验 |
| 3 | 移动庭院 `movement_garden.tscn` | 按上下文推断；即使实际指的是地形接触训练场 `ground_contact_course.tscn`，仍落在同一缺陷族（见下） |
| 4 | 人物动作工作台 `motion_stage.tscn` | 本轮新增报告：白色长条 / 网格在移动时闪烁；该场景是**运行时程序几何**（无 GLB），与前三处同属「水平面共面 + 双面穿叠」缺陷族，另多一层透明 alpha 排序因素（见第五场） |

报告只描述现象，未给出截图或逐帧证据。**现象定性**来自只读横向审计与镜头实验室 owner 的像素探针：装饰层与承托面共面或相交，双面材质让背面也参与光栅化，叠加连续微动的正交相机，使移动时出现深度/边缘重新取样闪烁。

- 共面使两个不透明面在同一深度竞争（Z-fighting）；双面材质让背面也参与光栅化，没有背面剔除稳定竞争结果；相机跟随移动时每帧采样栅格都在变，闪烁在移动中最明显。
- **透明排序排除只对上一轮 GLB 成立**：那批 GLB（三个场景 + 地形接触训练场，共四个）全部 `alphaMode = OPAQUE`，没有透明面参与排序；**人物动作工作台不适用该结论**——它的地面标记是运行时 `StandardMaterial3D`，修复前 7 个颜色带 alpha 0.35–0.9 并走 `TRANSPARENCY_ALPHA`，双面 + 体积穿叠使绘制顺序直接决定画面，alpha 排序是本场闪烁的参与因素。
- 不是 Godot 引擎缺陷：同引擎下 `mountain_realm` 用 2 cm 抬升约定即可避免；程序地面全部是 `StaticBody3D` + `BoxShape3D`，没有任何 `MeshInstance`，问题只在 GLB 内部的装饰层互相共面。
- **冻结相机的静止对照为零差异**（镜头实验室探针：关闭 physics 后连续 6 帧 changed-ish px = 0，144000 采样点），因此只截单张静止图会得到假阴性，评估与回归必须以**移动中**的画面为准。

共面实测（原审计口径：水平重叠 ≥0.05 m² 且垂直重合 ≤1.5 mm）：状态切换压力场最大共面对面 `Jade disc body ↔ Jade disc rim band` 顶面=顶面 **322.56 m²**；御剑飞行训练场 `landing_far ↔ landing_far_rim` 顶面=底面 **71.34 m²**；移动庭院 `Sand garden surface` 上下穿跨 `Limestone upper terrace` 顶面，另有约 131 组近共面对；地形接触训练场独立扫描命中 128 组，其中 `step_*_top` 属 A 类漏改点。

两类共面必须分开处理，否则允许清单会互相污染：

- **A 类：水平装饰层与水平承托面共面**（围边、压顶、铺装、自发光标记）。两片大面积同深度竞争，是闪烁主因；修法是抬升装饰层。
- **B 类：竖直物体的底面正好落在水平地面上**（竹干、柱脚、旗杆底）。接触处是小面积水平端盖与大平面共面，严重度低；修法是**把物体下沉埋入地面**，而不是抬升。

## 决策

修复在四个生成器的**源几何**上完成，重导出 GLB；禁止手改 GLB（生成物会被下一次重跑覆盖，也会让台账哈希失效）。沿用 `mountain_realm` / `peak_courtyards` 已验证的「装饰面高出承载面 2 cm」约定，`state_transition_lab` 的桥面例外处理。**不靠改相机、近平面、阴影、MSAA、曝光或模糊掩盖问题**；相机与输入手感不是根因。

### 第五场：人物动作工作台（运行时程序几何，无 GLB）

`motion_stage.gd` 在 `_ready()` 里用 BoxMesh / CylinderMesh / TorusMesh 程序化搭建全部标记：本场是**程序生成而非 GLB 资产**，不经过 Blender 生成器，也没有 GLB 可重导出。因此本场修复直接在运行时代码里改几何与材质，不新增二进制资产、不触碰任何探索资产。

本场相机跟随角色移动：角色一动，整片地面标记就在采样栅格上连续微动，闪烁只在**移动时**明显，静止单帧不能作为判据（与其它四场的移动观察口径一致）。

修复前实测（运行态 `motion_stage.tscn` 的真实节点几何）：

| 缺陷 | 实测 | 类别 |
|---|---|---|
| `FloorPlate` ↔ `RunwayBed` | `FloorPlate` y ∈ [−0.04, 0]（顶面 y=0）与 `RunwayBed` y ∈ [0, 0.012]（底面 y=0）在 **y=0 精确共面**，水平重叠 32 m × 3 m = **96.0 m²** | 零间隙承托共面（A 类） |
| `RunwayBed` / `RunwayCenterLine` / `Stripe*` | 三个半透明双面 BoxMesh 体积穿叠：bed y ∈ [0, 0.012]、centerline y ∈ [0.005, 0.015]、stripe y ∈ [0.008, 0.020]，层间净空为 0 | 透明 + 穿叠 |
| `TurnPadDisc` / `FlightPadDisc` 顶面 ↔ `Spoke*` 顶面 | 精确共面于 y=0.022；spoke 体积埋在 disc 里（spoke 底 0.010 < disc 顶 0.022） | 共面 + 穿叠 |
| `TurnPadRing` / `FlightPadRing`（flat ring 由平放的 `TorusMesh` 建模） | 管半径 0.10、圆心 y=0.014 ⇒ 最低点 y=−0.086 **穿出地板**；环中心半径 3.20 与 disc 边缘同半径，环管切进 disc 体积 | 穿地 + 穿盘 |
| `RulerBase` | 底面 y=0.006 悬空，未按其它场景的 2 cm 抬升约定 | 同族水平标记 |

修法决定是**保持物理地面碰撞盒顶 y=0 不变**，只把可见标记整体抬到地面之上，而不是下沉可见面回避共面；具体为 `物理地面顶面(0) → GROUND_MARK_BASE(0.02) → MARK_LAYER_CLEARANCE(0.004)` 逐层抬升，实际层间净空为 4 mm；机械断言与负向控制采用的**判据下界为 1.5 mm**（取自「垂直重合 ≤1.5 mm 即视为共面」，低于实现余量）；同层不同水平位置的标记允许同高：

| 层 | 底面 y | 厚度 | 顶面 y | 说明 |
|---|---|---|---|---|
| 物理地面 `Floor` 碰撞盒 | — | — | **0.0** | 未改；无网格 |
| `FloorPlate` | −0.040 | 0.040 | 0.000 | 可见地面基准，未改 |
| `RunwayBed` | 0.020 | 0.006 | 0.026 | 沿用 2 cm 抬升约定 |
| `RunwayCenterLine` | 0.030 | 0.004 | 0.034 | 高于 bed 4 mm |
| `Stripe*` | 0.038 | 0.006 | 0.044 | 高于 centerline 4 mm；交叉层级固定为 stripe 最上 |
| `*PadDisc` | 0.020 | 0.006 | 0.026 | 与跑道同基准 |
| `Spoke*` | 0.030 | 0.005 | 0.035 | 高于 disc 4 mm，不再埋进盘体 |
| `*PadRing` | 0.039 | 0.006 | 0.045 | 真实扁平环，不再穿地 / 穿盘 |
| `RulerBase` | 0.020 | 0.004 | 0.024 | 与其它地面标记同基准 |

三条修复规则：

1. **单调净空**：删除“标记中心写成承托面 + 自身半高”的写法，改为显式常量分层（`GROUND_MARK_BASE`、`MARK_LAYER_CLEARANCE`）；**垂直相邻层之间**的零间隙与体积交叠在结构上不可能出现。该保证只覆盖垂直相邻层：同层不同水平位置的标记允许同高，同层同色的重叠件（见允许清单）不在其内。
2. **不透明方案**：`_mark_material()` 强制 `TRANSPARENCY_DISABLED` 并把 alpha 归一为 1.0；7 个原半透明颜色改成「原 alpha 合成到最近承托面（或背景）」的等效不透明色，保持大致观感。不使用 `render_priority`、`no_depth_test`、`grow`、相机参数或 MSAA 掩盖。
3. **扁平环几何**：平放环改为 `SurfaceTool` 程序生成的矩形截面环带（内 / 外半径 + 厚度），替代管半径 0.10 的巨大 Torus；竖直 `HeightRing*` 保持原 Torus 与绝对高度语义（它们是高度参照，2 m 环下缘低于地面属于参照本身，本轮不改，列入限制）。

机械验收（`src/tests/test_motion_stage_geometry.gd`，进 `test_runner` 套件；`motion_stage_playtest.gd --batch=surface` 运行同一组关键不变量）实际只断言**固定的垂直相邻层对**——`FloorPlate → RunwayBed → RunwayCenterLine → Stripe*`、`FloorPlate → *PadDisc → Spoke* → *PadRing`、`FloorPlate → RulerBase`：上层底面必须高于下层顶面且净空 ≥1.5 mm（不做全节点两两 AABB 相交扫描，不做体积相交扫描）；**材质断言**要求全部量具 `transparency == TRANSPARENCY_DISABLED` 且 alpha=1；**Floor 断言**要求物理地面碰撞盒顶精确 y=0 且 `Floor` 子树无任何 `MeshInstance3D`。三能力装配与公开输入 API 的断言由 `motion_stage_playtest.gd` 的 `assembly` 批次覆盖，不在本几何专项测试内。修复前的几何（共面 96.0 m²、disc↔spoke 顶面同高、环穿地）会让该用例失败。机械断言只覆盖静态几何与材质，不能替代 **移动 playtest**：是否仍在移动中闪烁必须在跟随移动中观察（见下方运行时证据表），静止单帧截图不构成验收。

**限制口径**：移动/冻结像素对照只在状态切换压力场形成了可判别的修复前后差异；移动庭院、御剑飞行训练场与地形接触训练场均**未形成可靠的移动像素判别**，其修复依据是静态几何与生成器自检，不是像素读数。冻结组的 0 px 只能证明静止时不闪，不能证明移动闪烁已消除。人物动作工作台同理：其修复依据是运行态几何的机械断言（**垂直相邻层**净空 ≥1.5 mm、材质不透明、碰撞顶 y=0），而不是像素差异读数；场景内平放的 `HeightRing*` 竖直高度环按设计保持穿越地面与盘面的绝对高度语义，不在本轮修复范围。

### generator-local 检查不是 Tier 0 门禁

四个生成器在导出前对本次生成的网格自检，失败即拒绝导出（`SystemExit` / `assert`）；`surface_clearance_report.json` 是生成器导出后自检输出。这些检查**只随生成器运行，不进入 `tools/verify/`、不参与 Tier 0、不带负向控制、当前不作为放行依据**。若将来要固化为 `tools/verify/verify_gltf_overlays.py` 并纳入 Tier 0，必须先按根 AGENTS.md 工程约定第 6、7 条补「故意共面案例被真实拒绝」的负向用例与 `fix=` 修复路径，否则只能称为一次性检查工具。移动庭院使用的静态间距检查脚本在仓外（`~/.cache/game-xiuxian-lab/surface-clearance/movement-garden/`），明确不进仓、不成门禁。

### 允许 / 限制清单

- **允许的 top/top 交叠**：`takeoff_mark` 与 `takeoff_mark_cross` 同为 `Gate glow` 材质、同水平面十字交叉，重叠处不产生可见竞争，列为允许项。
- **允许的同层重叠（人物动作工作台）**：`TurnPad` / `FlightPad` 的 8 根 `Spoke*` 同层同色，辐条在盘心互相重叠；重叠处输出同一颜色，不构成可见材质竞争。它们**不在层间净空断言的比较对里**（断言只比较垂直相邻层，不做同层两两体积相交扫描）。
- **允许的埋入 bottom/bottom 重合**：`state_transition_lab` 的竖直构件端盖（门槛 −10 mm / 墙身 −12 mm / 柱 −14 mm 等）被实体包住、不可见；`ground_contact_course` 修复后仅存的 8 组均为两个已下沉端盖底面同深度（3 组 `step_*_plinth ↔ step_*`、2 组墙角墙脚互对、2 组台地栏杆墙脚互对、1 组院墙互对）。判据是「是否可见竞争」，不是「是否出现在扫描命中里」。
- **限制（断言范围）**：人物动作工作台的机械断言只检查命名的**垂直相邻层对**，不做全节点两两 AABB / 体积相交扫描；本 note 提到的「零穿叠」仅指这些垂直相邻层对之间无区间相交，不是全场景任意两个网格的无穿叠证明。
- **限制**：御剑飞行训练场扫描器只检 support top ↔ child bottom；`unregistered=0` 不代表 top/top、bottom/bottom 共面全为 0。移动庭院未做修复后全 GLB 重扫，同水平面内部相邻件（如 `Meditation stone top` 与 `Celadon bowl` 的竖直关系）未逐一判定。`mountain_realm` / `peak_courtyards` 未扫描。

### 资产保留事故与恢复

移动庭院重导时 Blender 自动产生的 `movement_garden.blend1` 与 `movement_garden.blend11` 曾被**误删除**，违反根 AGENTS.md「探索资产不得删除」。已按 git HEAD 的修复前字节恢复两个路径（sha256 均为 `f99acf09…`，Blender 可正常打开、319 网格），并在台账逐项登记来源与关系；生成器已设 `save_version=0`，后续重跑不再产生新的轮转文件。本轮集成补齐了仓内修复前归档：移动庭院的 `pre_surface_clearance_movement_garden.blend` / `.glb`（逐字节等于基线提交 `240c23c` 的旧字节）与地形接触训练场的 `pre_surface_clearance_ground_contact_course.glb`（逐字节等于 `0d1dc64` 的旧字节）；状态切换压力场与御剑飞行训练场的 `pre_surface_clearance_*` 归档此前已入库。全部 `.blend` / `.blend1` / `.glb` / 预览 PNG / 归档与报告均保留，未删除任何探索资产。

### 未改动的边界

- **能力**：不新增 Capability，三能力与唯一物理提交点不变。
- **碰撞**：四个场景的可走面、碰撞盒数值与碰撞 JSON 全部未改（桥面例外为可见顶下沉，碰撞盒顶保持 y=0）。
- **相机 / 阴影**：相机参数、跟随速度、近远平面、阴影设置、MSAA、曝光均未改动，也不作为修复手段。
- **人物动作工作台（第五场）**：物理地面碰撞盒顶 y=0、角色出生高度、三能力装配、公开输入 API 调用、固定机位偏移 / 跟随速度 / 正交参数、MSAA 开关均未改；只改可见标记的高度分层、几何与材质。

## 备选方案

- **只改运行时相机参数（近平面/远平面/投影）**：不采用。三场景的闪烁与 `far = 120 / 300 / 400` 的差异无关（`far` 最小的庭院同样闪烁），且相机是正交投影、深度线性；共面才是根因，改相机属于掩盖。
- **写 shader 给地面加 polygon offset / 深度偏移**：不采用。逐材质打补丁会把缺陷固化进运行时材质，且无法覆盖「同一个 GLB 在别处被复用」的情况；根因在资产，修在资产。
- **给地面标记设 `render_priority` / 关闭深度测试 / 改相机参数掩盖透明排序**：不采用。这些手段只改绘制顺序，不改几何关系；静止时看不出问题、移动时仍会闪，而且会把缺陷藏起来。人物动作工作台改为「严格净空 + 不透明材质 + 真实扁平环」。
- **只修当前反馈的三个入口**：不采用。共面来自四个生成器共享的同一写法，只修单处必然遗漏其余同源问题；`ground_contact` 已确认有同类漏改点（`step_*_top`）。
- **删掉装饰层网格来消除共面**：不采用。装饰层是观感的一部分（围边、压顶、铺装、自发光标记），删掉会让实验场景失去可读性；正确做法是保留几何、改高度关系。
- **声明这是引擎缺陷并等待引擎修复**：不采用。三个 GLB 全部双面 + 精确共面是可复现的资产条件，同一引擎下的 `mountain_realm` 用 2 cm 抬升即可避免，说明引擎行为正确。
- **把三个场景的装饰件整体重做为合并单网格**：不采用。超出当前探索范围，且会破坏「装置名 = 网格名」这一支撑 playtest 可视/碰撞对齐断言的命名契约。

## 后果

- 四个已确认场景的 A 类共面已按下表口径清零或转为允许项：状态切换压力场 22 → 0；地形接触训练场 121 → 8（全部 B 类允许，未允许 A 类 = 0）；御剑飞行训练场由生成器自检保证 11/11 登记对 OK 且未登记（support top ↔ child bottom 方向）0 对；移动庭院由生成器顶点自检与一次性 13 PASS 静态检查保证「装饰层 ↔ 承托层」间距。修复前静态计数与不同阈值口径见上表，不得混称。
- 运行时证据只在状态切换压力场形成判别（隐藏 rim 差异比约 18× → 约 1.1×，冻结 0 px）；移动庭院、御剑飞行训练场、地形接触训练场**未形成可靠的移动像素判别**，不得声称其闪烁已由像素证据消除。
- 四个生成器现在会在导出前自检，失败即不导出；这些检查不是 Tier 0 门禁，也不带负向控制与 `fix=`。移动/冻结像素探针中，状态切换压力场的探针脚本与日志保留在仓外缓存，地形接触训练场的实验脚本以 experimental / 非门禁状态入仓。
- 所有修复都从生成器重跑得到；资产台账的字节与 sha256 已同步更新，修复前源与导出以仓内 `pre_surface_clearance_*` 归档保留。探索资产保留事故已恢复并登记，`save_version=0` 防止后续重跑再覆盖历史备份。
- 能力、碰撞、相机、阴影均未改动；桥梁可走面顶下沉 5 mm 是唯一「改可见几何而非抬高」的例外，碰撞盒仍保持 y=0。
- 人物动作工作台（第五场）是唯一不走 GLB 生成器的修复：运行时程序几何按 `GROUND_MARK_BASE = 0.02` 与 `MARK_LAYER_CLEARANCE = 0.004` 分层，`_mark_material()` 强制不透明，平放环换成 `SurfaceTool` 矩形截面环带；新增专项机械测试，修复前几何会让它失败。该场景的运行时验收见 [工作台验收](../../../docs/playtest/2026-09-18-motion-stage-surface-shimmer.md)。
- 验收与台账：移动庭院见 [地表间距验收](../../../docs/playtest/2026-09-18-movement-garden-surface-clearance.md)，状态切换压力场见 [压力场验收](../../../docs/playtest/2026-09-18-state-transition-lab.md) 的「共面闪烁修复复验」小节，御剑飞行训练场见 [资产台账](../../../docs/art/sword_flight_course/asset_ledger.md) 的「共面闪烁修复」小节，地形接触训练场见 [资产台账](../../../docs/art/ground_contact_course/asset_ledger.md) 的「共面修复」小节。抬升约定沿用 [群山移动契约](../gameplay/2026-09-18-mountain-traversal.md) 与[探索资产保留](../process/2026-09-18-exploration-asset-retention.md)。
