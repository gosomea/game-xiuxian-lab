# Note: 保留现役人物网格，重做全部移动动画

Status: implemented

## 问题

使用者于 2026-09-26 以水墨线描城镇画面明确了最终画风，又指出所有移动场景人物站不正、动作气质不符，要求废弃此前的动作优化方向并重新制作。随后明确：**人物模型可以暂时保留，重做的是动画，不是人物**。现役 `cultivator_tripo_v9` 的贴地标定只处理每段动画的最低网格顶点；骨盆与脚、鞋底、站姿剪影仍不符合使用者验收。旧表现层以通用库动作和单段手作姿态覆盖全部运动状态，也不能仅靠播放速率变成新的动作语言。

## 决策

1. **新动画资产另存，不覆盖旧探索资产。** `cultivator_xianxia_motion_v1` 继续使用 v9 已清理的网格、纹理和蒙皮；旧模型与旧动画 GLB 原样保留，现役 `swordsman.tscn` 切到新动画资产场景。
2. **从骨架绑定姿态重新制作完整动作时间线。** 使用者再次明确原有动画全部删除重做；因此 `cultivator_ink_v2` 也只是中途试验，不接现役。新版本在导入旧网格和蒙皮后立即移除所有旧 Action，不采样旧动画任何一帧。从绑定姿态逐骨制作七段新动作，站立基线为脚底 y=0、骨盆在双足支撑范围上方、双脚朝前且鞋底平行地面。
3. **动作词汇取修仙语境。** 步行是克制的“行云步”，脚有明确交替支撑、上身不作西式摆臂；疾行是轻身急步，步频和步幅提升，手臂保持收束；跳跃是屈膝蓄势、提膝腾起、收势落地；御剑是双脚前后错步且膝微屈、身形稳定。原 `meditate` 插槽改演示“站桩吐纳”，双手聚于身前、缓慢呼吸：现有 22 骨没有手指骨，从绑定姿态强行做盘腿结印只会形成畸形姿态。该插槽不在行走状态中自动触发。不能仅把通用跑步动作放慢或将整体模型倾斜。
4. **保持物理接口。** 三个移动 Capability、速度、碰撞根和唯一 `move_and_slide()` 不变。新动画继续消费 `SwordsmanMotionComponent` 的只读状态；动作和物理分离。动作 clip 使用现有公开名称，以便动作工作台与旧测试继续验证真实播放源。飞剑仍使用现有装配，本轮只改人物动画。
5. **先在动作工作台验收，再统一接入。** 以正、侧、斜侧真实渲染验证中性站姿和六类运动状态，检查脚底、朝向、鞋剑关系和可读性；随后在庭院、群山、青玉样板等共享场景运行回归。审美是否最终达标仍由使用者判断，不以自动断言替代。
6. **2026-09-27 站立偏好修订。** 使用者明确要求普通站立，不再默认背手。现役人物静止、重置和暂停预览统一使用新制 `idle`（双臂自然放松）；`idle_guarded` 仅作为探索资产和工作台显式演示保留，不由移动状态自动选中。改变默认选择即可，不重做人物、不覆盖或删除既有动画资产。

## 备选方案

- 在 v9 的七段动作上继续施加全局腿链旋转：不采用。它已在试验里对 `meditate` 不收敛，并让 `walk` / `run` 的最低顶点再次浮空；更无法改变人物细节和动作气质。
- 给各场景单独调 Visual 偏移或镜头：不采用。八个入口共用一份人物装配，逐场景补丁会掩盖同一资产问题。
- 只换材质或全屏描边：不采用。错误重心与动作轮廓在剪影中仍可见；要从形体和动作源头调整。
- 删除旧 v9 与历史素材：不采用。探索资产保留要求源文件和导出物仍在仓内，可作为故障对照与回退。
