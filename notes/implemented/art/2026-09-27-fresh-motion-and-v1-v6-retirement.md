# Note: 现有人物骨架上全新制作移动动作并删除 v1–v6 试验资产

Status: implemented

## 问题

使用者否决了“CMU v6 走路 + v1 其余六段”的拼接方案，要求整个 v1–v6 动作版本删除，重新制作所有移动动作；随后确认人物建模 v1–v6 也删除。仅修正躯干倾角不能解决整体动作语言不统一。正式移动链目前曾在未提交工作中接到拼接 v2，必须先撤销这条接入，避免它变成实际交付。

## 决策

1. 仅保留当前允许暂用的 v9 人物**网格、材质、22 骨骨架和蒙皮**。新动画源从 v9 的绑定姿态开始，导入后立刻移除其所有旧 Action；不读取 v1–v6 或 v9 旧动作的任何采样帧。新动作库至少包含普通站立、步行、疾行、跳跃、御剑与工作台正在调用的额外状态，全部重新制作。
2. 行走采用早期分件版“中轴直立、步幅克制、速度决定节奏”的观感，但在同一骨架上构建完整支撑与摆腿，避免以整个人物旋转冒充转向。疾行、跳跃、御剑分别制作独立动作，不使用 v1 手作轨道、CMU v6 动捕或旧 Mixamo 动作填空。
3. 用全新命名的 Blender 源、GLB 和视觉场景接入 `swordsman.tscn` 与动作预览；原人物 v9 的静态数据可继续作为构建输入。提交前量蒙皮鞋底、躯干倾角、脚下重心、循环接缝与游戏速度；通过独立场景实际截图和移动场景回归。
4. 新版接入且引用清单确认后，删除人物建模 v1–v6 及动作试验 v1–v6 的源、导出、贴图、预览和专属构建脚本/场景；清理引用它们的测试与目录入口。保留不属于这两个版本序列的 v7–v9 人物、其它游戏模块和第三方原件（若有非废弃依赖）。用户本轮明确的删除指示覆盖项目此前的探索资产保留约定；不改写 Git 历史。

## 备选方案

- 继续校正 CMU v6，再沿用 v1 其余六段：使用者已明确否决；动作语言依旧分裂。
- 只在运行时隐藏 v1–v6 文件：不满足“全部删掉”，也不能减少无用资产与错误入口。
- 一起重做 v9 人物网格：使用者此前允许暂时保留该人物；当前问题是动画。

## 后果

- 现役七段动作由 `tools/art/build_cultivator_motion_20260927.py` 生成，产物为独立 Blender 源文件和 `cultivator_motion_20260927.glb`。从 v9 网格和骨架导入后删除全部七个旧 Action，`build_manifest.json` 记录旧动作采样帧为 0。普通站立双臂下垂，`idle_guarded` 改为待命姿态；步行与疾行按实际脚趾行程和周期估算自然速度约 1.59 / 2.28 m/s，对应角色 1.55 / 2.25 m/s。
- 默认 `swordsman.tscn`、动作预览、青玉纸样板和测试统一使用新视觉场景。原 v1–v6 建模与废弃动作试验共 444 个被跟踪文件已从当前树删除；完整路径清单为 [retired_assets.json](../../../docs/playtest/2026-09-27-fresh-motion/retired_assets.json)。Git 历史不改写。v7 的构建仍依赖某第三方原件，已把其原始 `.blend` 从删除的 v5 目录迁到 v7 自有 `source/`，并更新构建脚本与台账；v7–v9 的运行时资产不删除。
- 蒙皮鞋底逐帧检查见 [ground_contact.json](../../../docs/art/cultivator_motion_20260927/ground_contact.json)，六段接地 clip 的逐帧最低点相对地面均在 3 mm 内；`jump` 片段的脚底最高离地约 0.14 m。骨架只有 22 根、无手指骨，手势细节仍受限。动作审美需要在用户实际试玩时继续判断；自动几何与脚本检查仅覆盖可量化的姿态、装配和状态行为。
- 本决策覆盖 [2026-09-26 现役人物动画重做](2026-09-26-ink-cultivator-runtime.md)中“保留 v1 动作版本”和“探索资产一律保留”的本轮实施方案。删除范围是使用者在 2026-09-27 明确指示的例外，不构成以后自动清理探索资产的通用授权。
