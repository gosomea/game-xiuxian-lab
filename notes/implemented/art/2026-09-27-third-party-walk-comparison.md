# Note: 现成人体步态在现役修士骨架上的独立对照

Status: implemented

## 问题

使用者指出现役 `walk` 怪异，要求先分析走路、疾行、跳跃、御剑各自动作来源，随后明确授权“可以，你试试”。现役 `walk` 只有五组关键姿态，脚交替摆动但缺少真人支撑期的骨盆与足掌细节；单靠贴地最低点不能判断滑步。需要在同一人物、同一速度和同一镜头下，看到现成动作重定向后的真实表现，再决定是否替换现役。

## 决策

1. 只对**普通步行**做这一轮动作来源比较。现役 `walk` 为基线；已有 KayKit Adventurers `Walking_A` 与 CMU Subject 16 的普通步行 BVH 作为两条外部候选。来源、许可、固定版本、哈希与下载原件进入资产台账。CMU 转换版需同时保存转换者声明，不能仅凭第三方镜像声称许可。
2. 保留现役人物的网格、材质、22 骨骨架和蒙皮。把外部动作重定向到它；不同骨架的同名轨道不得直接拼接。候选导出单独的 Blender 源与 GLB，不覆盖 `cultivator_xianxia_motion_v1`、旧 v9 或外部原件。
3. 先检查一周期是否能稳定重复、双脚支撑期是否滑动、骨盆是否站在脚上、鞋底是否穿地、上身与双手是否符合普通修士自然行走。候选失败也保留源、导出与截图，并标注失败原因。
4. 验证载体为独立移动动作对照实验与可回放的视觉证据；现役 `swordsman.tscn`、移动能力和所有原有场景不切换。只有对照明显优于当前步态，才另轮讨论现役替换。

## 备选方案

- 直接把 KayKit GLB 角色作为新人物：不采用；使用者已明确只改动画，暂时保留现有人物。
- 直接把旧 v9 `Walking` 接回来：不采用；该动作链此前已出现重定向、倾斜与滑步问题，且使用者明确废弃此前动画。
- 本轮同时替换疾行、跳跃和御剑：不采用；先把普通步行来源与技术管线验证清楚，再按动作语义分别处理。

## 后果

本轮有文件改动即遵守 Git 保存、资产保留与全量入库规则。候选是否最终符合修仙气质，以同视角可见证据和使用者审看为准；结构测试与贴地数字不能代替审美结论。

## 实施与本轮结论

完成 [资产台账](../../../docs/art/cultivator_walk_sources/asset_ledger.md)、两个候选的独立 GLB / Blender 源、[同镜头对照场景](../../../src/levels/experiments/character_movement/walk_source_comparison.tscn)及窗口模式截图。人物网格、材质、骨架不变，现役动画与所有原移动场景未改。CMU 稳定周期更接近日常修士步行，可继续打磨重心和足底；KayKit 的高抬膝与手部后收不宜直接替换。候选均未升级为现役，等待连续实机观看后的审美判断。
