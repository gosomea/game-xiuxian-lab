# Note: 清理未接入实验目录的旧人物模型与动作

Status: implemented

## 问题

角色移动已切到 `cultivator_aligned_motion_20260927`，旧人物、动作候选及其独立测试仍占据运行时目录和大量仓库空间。使用者确认当前基本动作可用，并明确要求删除剩余未使用的动画与模型、提交和推送。原有[探索资产保留决策](../process/2026-09-18-exploration-asset-retention.md)要求默认保留废弃版本；本次明确删除要求是针对这一批旧人物资产的例外，不扩大为环境、飞剑、已登记模块或未来资产的通用删除规则。

## 决策

以 `experiments.json` 已登记且可运行的场景及其资源依赖为使用边界，保留现役人物 GLB、贴图、视觉场景、七段动作、可编辑源和验证材料。将现役 GLB 重新导入为自包含 Blender 源，保留全部七段动作和内嵌贴图；导出脚本只依赖该源，随后删除已不参与运行或重建的旧人物源、导出、场景和旧版本专属测试。停用的 KayKit 角色路线和未接入实验目录的蓝鲸女仆模型也属未使用人物候选，连同各自源和导出移除。环境地形、建筑、飞剑、二维画风探索图及其源保留。

清理需同步修正现役测试中“旧视觉必须可加载”的断言、资产台账与项目状态说明。历史决策 note 与试玩报告保留为过程记录；它们提到的旧路径不再是现役资源入口。删除清单以本次 Git 提交为准，旧文件可从提交前的 `ca78c86` 恢复。

## 备选方案

- 只从场景取消引用、资产继续留在 `src/`：未达到使用者提出的清理目标，旧版专属测试还会继续把旧资源当成必须交付的内容。
- 保留整条旧 Mixamo 和 v9 源管线以重跑角色生成脚本：现役 GLB 已包含最终蒙皮与七段动作，重建可转为自包含源；旧候选和大量中间件不再是必要输入。
- 清理所有 `docs/art/` 中未直接被运行时加载的模型：会误删地形、建筑和飞剑的可编辑源，破坏仍在运行的实验模块。

## 后果

运行时角色目录只保留现役人物和仍被实验场景直接使用的资源；旧人物对比版本不再提供独立场景或测试。之后若要修改动作，从现役 Blender 源编辑并导出，需重新检查骨架、七段 clip、贴地和运行时状态切换。历史报告中的旧素材链接可能失效；此清理不声称那些历史实验从未发生。

本次从工作树移除 895 个已跟踪旧资产及专属工具/测试文件，按删除前 Git blob 大小合计约 8.73 GiB；Git 历史未改写。现役源重导出的临时 GLB 通过七段动作、朝向摆臂、姿态和逐帧贴地检查；`python3 tools/verify/run_all.py --with-tests` 通过 Tier 0、27 项负向控制和 1096 项运行时断言。旧测试移除后断言总数下降，不代表现役动作验收被移除。
