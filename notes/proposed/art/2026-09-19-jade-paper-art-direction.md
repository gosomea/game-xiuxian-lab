# Note: 青玉纸白：统一世界美术方向与可执行造型规格

Status: proposed

## 问题

项目已有多个场景与一批程序建模资产，但**没有一份统一的世界美术规格**：环境参数在 8 个场景里各写一套，世界基调与实验外壳（UI/工作台）的纸白青绿混用，对象级造型（人物、岩体、建筑、植被）只有零散台账读数、没有正向要求。继续由每个场景各自决定，资产会持续漂移，跨场景一致性无法验收。

使用者已于 2026-09-19 认可一条方向（见下原句）。仓库里另有五张 AI 概念图归档；它们只作参考，其描述偏差已在 [style_exploration README](../../../docs/art/style_exploration/2026-09-19/README.md) 的「参考边界」表中逐板纠正。

本 note 只写规格、边界、交接与验收；**资产与运行时均未实施**。实现由使用者另找他人执行，本 note 不含代码、测试脚本或生成器改动。

## 提案

### 1. 本次风格依据（使用者认可）

> 国风动画化造型，精致低模生产，温润 PBR 材质，青玉暖木色卡，水墨意象远景，角色与飞剑保留细轮廓，场景通过光影和雾形成层次。

方向已认可，作为本次风格的依据；实施仍遵守仓库既有规则（架构与资产纪律、[notes 决策流程](../../README.md)、探索资产保留与入 Git 等）。文字是依据，五张图只是参考；图面与文字冲突时以文字为准。

### 2. 正向造型规格（逐对象执行）

| 对象 | 必须做到 | 避免 |
|---|---|---|
| 人物·整体 | 国风动画化比例；**6.5–7 头身为起始建议**；站姿与运动剪影可辨 | 为追完成度堆半写实细节 |
| 人物·衣 | **交领、腰封、袍摆**三条线清楚；袍摆有垂坠与分片 | 直筒裙、无腰线、衣纹糊成一片 |
| 人物·头 | **发髻**成立、发际线可读 | 整块黑球头 |
| 飞剑 | **脚踏飞剑**：剑在脚下、剑体可辨、**足与剑相接** | 俯身手持剑的飞行姿态；剑与脚脱开、剑不可辨 |
| 人物·脸/手/露肤与袖口、檐口（近景收口） | **平滑优先**：形体干净、收边干净、转折简洁 | 褶皱细节、噪点、写实皮肤、硬折、锯齿、碎面 |
| 山岩 | **保留大块面**，体块与棱线分明 | 碎片化、噪声堆坡 |
| 建筑 | **台基 / 柱梁 / 墙 / 门 / 屋檐 / 屋脊分层清楚**，每层读得出 | 一整块盒子、层与层粘连 |
| 建筑·尺度 | 与人尺度对应：门口可走、台阶与构件符合人参照表 | 纪念碑式比例、人门比例失衡 |
| 松 | **偏斜、分层冠** | 正圆锥、等距对称 |
| 竹 | **竖向成簇**，有疏密与朝向 | 随机撒点、单株均布 |
| 植被整体 | 成组、有聚散与坡位关系 | 均匀随机散布 |
| 地面/铺装 | 灰米色系，分格与收边可读 | 大面积纯白、无收边 |
| 远景 | 剪影为主、降对比 | 与近景同对比、细节堆满 |

### 3. 色卡与层次

| 用途 | 颜色 |
|---|---|
| 角色主色 | **靛青** |
| 角色辅色 | **月白**（内衬/交领）+ **少量淡金**（腰封/纹样） |
| 瓦 | **青玉** |
| 木 | **暖棕** |
| 岩 | **青灰** |
| 植被 | **深松绿** |
| 地面 | **灰米** |
| 天空 | **低饱和青蓝** |

| 层次/效果 | 做法 |
|---|---|
| 近景 | 承担**材质**细节 |
| 中景 | 承担**构图**关系 |
| 远景 | 只做**剪影**并降对比 |
| 阴影 | **保留体积**塑形；**不用雾把画面洗平**；斜光下阴影随高度偏移是自然现象，不强制角色正下方有影 |
| 轮廓 | 角色用**细深青灰边**，随距离稳定；**场景不做全场粗黑边** |

### 4. 制作与资产纪律

- **生产工具是 Blender**（程序或手工建模均可）；新方案**另存文件名或版本目录**，不覆盖旧 `.blend`/`.glb`，并登记替代关系（[exploration-asset-retention](../../implemented/process/2026-09-18-exploration-asset-retention.md)）。
- **导出走 GLB**，保持既有轴向、共面（装饰面高出承载面）与「源在 `docs/art/`、导出在 `src/`」分工；旧台账读数不因本轮改写。
- **色彩空间显式约定**：GLB `baseColorFactor` 是线性值；色卡同时给出线性值与目标显示亮度——这是上一轮「纸白被曝光洗白」的根因（[群山视觉重建](../../implemented/art/2026-09-18-mountain-realm-visual-rebuild.md)）。
- **共享材质与环境**：色卡、光照与雾作为可复用共享定义，不再每场景各写一套。
- **模块化建筑与植被**：构件可组合复用；植被与地形分开归属。
- **景观呈现层与实验工具层分开**：实验量具（动作台的跑道、刻度盘、中性背景）保持**干净中性**，不被色卡或雾染指。
- **PBR ≠ 写实**：温润 PBR 指物理化粗糙度与柔和受光，不是写实描摹；**允许角色贴图**（含手绘风）与**骨骼**。
- **预算不预设**：面数、骨骼数、场景总量、贴图数量与是否使用 toon，留待试制后按目标设备实测冻结。

### 5. 运行时与相机边界

- Capabilities 数据通信与**唯一物理提交点**不变；表现层只**读**运动状态，风格代码不耦合物理。
- **不武断禁止新的表现 capability**，也不把表现塞进物理层。
- **相机不是待冻结的固定选择**：CameraRig 的实际模式 ID 为 `fixed_follow` / `quarter_turn` / `orbit` / `overview`（`MODE_ORDER`，见 `src/levels/experiments/character_movement/camera_lab.gd:24`），右键环绕是 **orbit 的既有需求**；配置默认只挂 `fixed_follow`（`camera_rig_config.gd:33`），镜头实验室与移动庭院默认进入 orbit。多模式与环绕必须兼容，不采用单机位固定作为验收前提。
- **渲染器沿用现有配置**；更换渲染器属单独决策，不在本方向内。

### 6. 交接与实施顺序

1. **小型样板**：含角色 / 飞剑 / 亭 / 台阶 / 松 / 岩石 / 远景的最小场景，一屏可比较。
2. **灰模比例 + 统一灯光**：先定形体、尺度与人参照表，统一主光与阴影方向。
3. **材质色卡**：青玉 + 暖木为主的共享色卡（含线性值与显示目标）。
4. **轮廓与雾**：角色与飞剑细轮廓；远景水墨意象层次与降对比。
5. **真实可运行验证**：Godot 真实运行 + 移动视频 + 多场景组合。
6. **使用者视觉验收**：唯一的审美结论来源。
7. **批量推广**：样板通过后才扩散到群山、庭院、宗门与其余实验场景。

优先级：**剪影可读性 > 真实骨骼动作 > 材质细节**。

## 备选方案

- **直接照 A 板追完成度**：不采用。A 是半写实华丽细节，与精致低模生产的产能目标不匹配——这是本项目的成本与权重取舍，不是技术不能共存。
- **把五张图加总成一套做法**：不采用。各板取向互相拉扯，会把产能分散在互相抵消的目标上；取舍在本项目，非技术禁止。
- **整套赛璐璐上色 + 描边为主**：不采用。它要求另一套光照与轮廓体系，与「光影和雾形成层次」「温润 PBR」的既定权重冲突；技术上可与 PBR 共存，只是不作为本项目主线。
- **只改材质与后处理**：不采用。方向同时约束造型、比例与轮廓；仅改材质会重演上一轮用曝光/压暗掩盖问题的老路。
- **维持现有纸白青绿世界基调**：不采用。那是实验外壳（UI/工作台）的配色，不是世界美术。
- **概念图直接当资产或贴图使用**：不采用。图不含可用几何，镜头与细节不受控，不满足轴向、共面与碰撞契约。
- **先批量重做五峰与全部场景**：不采用。未经样板验证就扩散，返工与覆盖风险不可控。

## 验收标准

每项均需可操作、可复核，并附截图/视频或读数：

1. **运行与可玩性**：样板在真实 Godot 中可启动、可移动、可录屏；记录**默认缩放**与**最小可玩缩放**下的画面。
2. **动作视频**：移动、跳跃、御剑三状态，各给**正 / 侧 / 背 + 环绕**视角的视频（多机位，含贴合近景与远景）。御剑需可读为**脚踏飞剑**（剑在脚下、剑体可辨、足与剑相接）；手持飞行图**不作为动作规范**。
3. **闪烁**：**暂停对照**甄别——同机位静止帧与移动帧对比；装饰面/承载面共面不回归（[coplanar-surface-shimmer](../../implemented/art/2026-09-18-coplanar-surface-shimmer.md)）。
4. **轮廓**：角色细轮廓在近 / 中 / 远三个距离上宽度与可见性**稳定**；场景无全场粗黑边。
5. **阴影**：**着地状态**的接触阴影贴合地面、不悬空不穿插；斜光导致的阴影偏移属自然现象，不作为缺陷；画面未被雾洗平。
6. **性能**：给出**帧时间 p50 / p95**，并记录硬件、分辨率、渲染路径与**移动负载**；**目标帧率在试制前约定**，预算在实测后冻结。
7. **尺度**：人参照表（人 / 门 / 台阶 / 灯 / 树 / 剑）与画面一致。
8. **风格**：逐条对照方向原句与第 2、3 节规格。
9. **资产保留**：旧资产未被删除或覆盖，新版本另存并登记，Git 内可查。
10. **结论归属**：自动化检查通过**不等于**视觉实现验收通过；**使用者视觉确认前不得宣称通过**。

## 风险

- 概念图细节不可复现，实施者可能按图追求不可达的完成度。
- 预算尚未实测，过度细化会导致产能与性能返工。
- 「水墨意象远景」与「温润 PBR 材质」在光照上需样板先验证兼容。
- 引入骨骼后动作风格可能与低模轮廓不协调。
- 试制期间容易误覆盖旧资产，须严格执行另存与登记纪律。
